# Bookstore Performance Analysis
Tableau analysis of bookstore performance, exploring sales, profitability and key business trends.
## Project Overview

This project uses Tableau to analyse bookstore performance and identify
patterns in sales, profitability and business performance.

The aim was to turn raw transactional data into clear visual insights that
could support business decision-making.

## Skills Demonstrated

- Tableau
- Data visualisation
- Dashboard design
- Filtering and interactive analysis
- Calculated fields
- Sales and profitability analysis
- Trend analysis
- Communicating business insights
